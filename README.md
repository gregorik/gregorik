### 🛠️ What I do for studios

Fixed-price work inside your project. You get a written report and before/after proof.

- **Google Play Compliance Pass (UE 5.5–5.8):** target API 36, Play Billing Library 8 and 16 KB memory pages, plus a preflight report of everything Play would reject. Google's extension window for API 36 ends on **1 November 2026**.
- **Stutter & First-Run Fix (UE5 PC / Steam):** a cold-cache hitch capture, the whole PSO pipeline (collection, bundling, precaching, warm-up) and scalability defaults for mainstream PCs.
- **Contract Unreal C++:** plugins, editor tools, build and packaging pipelines, and gameplay systems.
